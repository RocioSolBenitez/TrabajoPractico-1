Breve explicación del Trabajo Práctico N°1

Este sitio web fue realizado para el Trabajo Práctico N°1 de la materia Informática General de la carrera Artes Multimediales en la Universidad Nacional de las Artes (UNA). El TP consiste en realizar un sitio web de 6 páginas; una página principal con información general sobre el sitio, una página para cada uno de los tres juegos, una de puntajes con records de cada uno, y, la ultima página, con información sobre las integrantes y el desarrollo del proyecto. Teniendo que utilizar las tecnologías HTML para la estructura de las páginas, CSS para el diseño y los estilos y JavaScript para las funciones e interacciones de los juegos.
